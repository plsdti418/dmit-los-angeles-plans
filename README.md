# 美国 VPS 推荐：先分清 CN2 GIA、9929 和 CMIN2 三条线路，再按运营商和预算挑洛杉矶机房

搜"美国 VPS 推荐"，出来一堆商家清单，配置看着都差不多，价格能差三倍。差价基本不在 CPU 和内存上，而在回程线路。所以这份推荐不按商家名气排，按线路和场景来分，最后落到一个具体的机器清单上。

## 先搞清楚你多花的钱买的是什么

美国机房到你家之间，国际段其实差别不大，真正拉开距离的是国内这一段骨干网。三大运营商各自有普通路和快速路，商家说的"优化线路"，本质就是给你买快速路的通行证。

| 线路 | AS 号 | 归属 | 实际情况 |
| --- | --- | --- | --- |
| 163 | AS4134 | 电信 | 老牌公众骨干，便宜，晚高峰国际出口一堵就抖 |
| CN2 GT | AS4809 | 电信 | 只有出口段走 CN2，进国内还是汇入 163，改善有限 |
| CN2 GIA | AS4809 | 电信 | 进出全程走 CN2，不和 163 混跑，晚高峰表现稳定，价格最贵 |
| 9929（CUII） | AS9929 | 联通 | 联通自建精品承载网，联通用户访问最稳 |
| CMIN2 | AS58807 | 移动 | 移动国际精品线，洛杉矶直连上海入口 |

判断方法很机械：在 VPS 上跑一次 traceroute，回程节点里出现 `59.43.x.x` 就是走 CN2，全程都是才是 GIA。别只看商家页面上的词，晚高峰八点到十一点再测一遍，白天测谁家都好看。

## 挑美国 VPS 时真正该问自己的几个问题

- 你的用户主要挂在哪个运营商？电信为主，CN2 GIA 的收益最大；移动、联通为主，9929 和 CMIN2 的组合更划算，价格还低一档。
- 流量用超了会怎样？是直接停机，还是降速继续跑。这一点比多给 20GB 硬盘重要得多。
- 面向国内还是面向国际？如果业务本身在欧美，压根不需要为中国方向优化付费，国际 BGP 的大带宽机型便宜很多。
- 能不能先月付？再稳的商家也建议先买一个月，测完路由和晚高峰再决定要不要转年付。
- 支付和退款：支持支付宝省事，退款条款写清楚的商家，试错成本才可控。

**电信宽带为主、要晚高峰不抖**：直接看 Premium。$10.9 的 Pro.TINY 是这条线里门槛最低的一档，1 核 2G 拿来跑代理、轻量站点够用；如果要正经营业，$34.9 的 Pro.STARTER 把带宽拉到 10Gbps、月流量 3TB，是这条线里比较均衡的一档。

**预算型个人用户**：T1.WEE 年付 $36.9 折下来每月三美元出头，4Gbps 端口，做海外中转落地、监控、备份这些用途性价比很高。

有第三方整理页面在 2026 年仍然列着一枚 Eyeball 系列的循环折扣码 `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF`，适用范围是 LAX EB TINY 及以上机型、非月付订单，力度约八折且循环生效，也就是续费同样打折。结算页填入后点 Validate Code 验证一下，能过就是有效，通不过就说明这一批已经不适用了。优惠码和平台批次绑定，别把 EB 的码套到 Pro 或 T1 上。

几个实际会遇到的问题：

- **流量跑完之后**。DMIT 的处理方式是降速不停机。Premium 超量后限到 4Mbps 左右，Eyeball 到 4 至 8Mbps，Tier 1 能保留 100 至 500Mbps。超量限速只影响大文件传输，SSH、轻量网页访问基本无感。
- **IP 被墙**。第三方信息显示官方提供每 15 天一次免费更换 IP 的机会，超出部分另外计费，具体规则以购买页面和工单回复为准。

- **先测再买**。官方提供 Looking Glass 和测试 IP，ping 和 traceroute 都能自己跑，晚高峰跑一遍比看十篇测评有用。
